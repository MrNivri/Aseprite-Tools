# Aseprite Tools

**Small tools, better workflows, more creativity.**

---

A collection of scripts, extensions, and utilities designed to improve the workflow of pixel artists using [Aseprite](https://www.aseprite.org/).

This repository aims to provide practical tools that make everyday tasks easier, faster, and more enjoyable.

---

## 🧰 Available Tools

Explore the collection and find the tools that fit your workflow.

| Tool                                                  | Description                                           | Status            |
| ----------------------------------------------------- | ----------------------------------------------------- | ----------------- |
| [Numbered_Layer_Exporter](./tools/Numbered_Layer_Exporter/) | Export individual layers from your Aseprite projects. | 🚧 In Development |

*More tools coming soon!*

---

## 📦 Installation

Each tool includes its own installation instructions.

1. Browse the tools listed above.
2. Open the folder of the tool you want.
3. Read its documentation.
4. Download and install it following the provided instructions.

---

## 🎨 Features

- 🧩 **Independent Tools:** Each script has its own documentation and files. Tools designed to improve everyday workflows.
- 🖼️ **Visual Documentation:** Previews and examples whenever available.
- 🌎 **Community Focused:** Resources created to help pixel artists.
